# =============================================================================
# wow_api_allowlist.txt
#
# Globale Namen, die es in World of Warcraft 3.3.5a (WotLK, Interface 30300)
# WIRKLICH gibt und die das Addon direkt lesen darf. Benutzt von tests/lint_globals.lua.
#
# Format: ein Name je Zeile (mehrere durch Leerzeichen sind erlaubt), "#" beginnt
# einen Kommentar. Eine Zeile "PREFIX*" erlaubt alle Namen mit diesem Praefix.
#
# NICHT hier (und damit ein Lint-Fehler beim Lesen):
#   * die Lua-5.1-Basis (print, pairs, string, table, ...): steht fest im Skript
#   * Addon-eigene Globals (Transmog, TransmogDB, TransmogWindow, ...): ebenfalls
#   * alles, was es in 3.3.5a nicht gibt (C_Timer, Mixin, SetShown, SOUNDKIT, ...)
#   * Lua-4-Altlasten (getglobal, getn, foreach, foreachi, sort): _G[name], #t,
#     pairs, table.sort benutzen
#   * unsichere Kandidaten: im Zweifel Util.G("NAME", "Fallback") statt direktem Lesen
#   * Namen, die nur als Abfrage erlaubt sind (RegisterAddonMessagePrefix,
#     SetDesaturation): stehen als OPTIONAL in tests/lint_globals.lua
#
# Neue Eintraege nur aufnehmen, wenn die Existenz in 3.3.5a sicher ist.
# =============================================================================
